# GamePygame

## О проекте

`GamePygame` — dungeon-crawler прототип с ASCII-представлением карты, генерацией комнат и коридоров, инвентарём, дверями, сундуками, предметами и несколькими типами боссов. Проект сочетает исследование подземелья, боевые столкновения и простую UI-обвязку с игровым чатом.

## Что внутри

- процедурная генерация карты с комнатами и коридорами;
- игрок, обычные враги и несколько вариантов боссов;
- двери, сундуки и выпадающие предметы;
- инвентарь с активными и пассивными слотами;
- ASCII-визуализация карты и отдельная зона сообщений внизу окна.

## Стек и структура

- Python
- `pygame`
- ключевые файлы: `main.py`, `dungeon.py`, `player.py`, `enemy.py`, `boss.py`, `items.py`, `doors.py`

## Запуск

```bash
python main.py
```
